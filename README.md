# 八宅游年盘 🏠

> 八宅风水「游年盘」速查工具：输入大门方位，一键排出四吉四凶八方星位。

支持两种取伏位的方式，一键切换：

- **门向法**：以大门所朝方向为伏位（只取四正：东→震、南→离、西→兑、北→坎）
- **门位法**：以大门所在卦位为伏位（八个卦位都可，含四隅）

排盘结果与《大游年歌》逐项一致，四吉（生气·延年·天医·伏位）绿色、四凶（祸害·六煞·五鬼·绝命）红色。

## ✨ 功能

- 🧭 门位法 / 门向法一键切换，盘面实时更新
- 📍 点宫格看星义（星名 · 五行 · 吉凶 · 主事 · 宜忌）
- 🏠 顶部结论：宅型（东四宅 / 西四宅）+ 四吉方 + 四凶方 + 开门建议
- 📤 导出 PNG 图、复制分享文案、打印 A4
- 💾 两个模式各自记住上次选择（localStorage，纯本地不上传）
- 📱 PWA：可添加到主屏幕、全屏运行、断网可用

## 🧱 技术栈

- 纯前端单文件，零依赖、零网络请求，断网可用
- 数据与逻辑分离：改文案 / 颜色 / 规则只动 `index.html` 顶部 CONFIG 区，不动算法
- PWA：`manifest.webmanifest` + `sw.js` 离线缓存

## 🚀 部署

把本文件夹放到任意 https 静态托管即可（GitHub Pages / Cloudflare Pages / Netlify / 自己的服务器）。

上线地址：<https://bazhai-you-nian-pan.netlify.app/>

本地预览：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

iPhone 使用：Safari 打开网址 → 分享 → 添加到主屏幕，即可全屏离线使用。
